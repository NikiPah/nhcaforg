# Patient experience

The assistance inquiry now uses a seven-step wizard inspired by the HealthWell screenshots provided by the user. It keeps the NHCAF name, colors and eligibility requirements. A progress bar, completed-step navigation, Previous/Next buttons, English/Español controls, Cancel/reset, and a final editable review guide patients through the application.

No account or document upload is required. Answers stay in memory until final submission. Back and language changes preserve them; edits reset the final acknowledgement. No SMS verification, credit inquiry, medication/insurance screening or broad third-party release was added. The existing Supabase inquiry API and database migration are unchanged. See [the current assistance inquiry design](assistance-inquiry.md) for the workflow, privacy model, and testing limits.
